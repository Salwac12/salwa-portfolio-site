# SalwaPortfolio

A minimalist portfolio built with a dark developer aesthetic inspired by [jayjr.vercel.app](https://jayjr.vercel.app/).

## Features
- **Canvas Cursor Follower**: Exact multi-trail spring-dampened cursor ribbon wave.
- **Aceternity UI Canvas Reveal Effect**: Ambient square pixel grid background with subtle periodic on/off pulsing and bottom fade gradient.
- **3D Flipping Avatar**: Interactive 3D flip card between Salwa's real portrait and animated avatar.
- **Widescreen 16:9 Project Cards**: Clean project video showcases with punchy one-line descriptions.
- **CIE First-Person Blogs**: Detailed first-person technical narratives with interactive reading modals.
- **Dark / Light Theme Toggle**: Seamless persistence via localStorage.
